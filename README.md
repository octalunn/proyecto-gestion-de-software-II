# Sistema de Gestión de Pedidos - Gestion de Software II

Este proyecto es un sistema para la automatización del ciclo de vida de los pedidos, desarrollado para la materia **Gestión de Software II**.

## Objetivos del Proyecto
* **Análisis de ventas**: Obtener datos precisos sobre la comercialización de productos.
* **Control de producción**: Supervisar el proceso de elaboración y stock.
* **Eficiencia**: Optimizar los tiempos de respuesta en el ciclo de pedidos.

## Actores Principales
* **Cliente**: Inicia la compra y consulta el catálogo.
* **Operador de Ventas**: Gestiona el despacho y emite comprobantes.
* **Administrador**: Controla el inventario y catálogo de productos.
